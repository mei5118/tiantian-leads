天天获客 Agent

面向线上运营小团队的获客自动化 AI Agent

天天获客 Agent 是一个跑在运营流程里的 AI Agent：自动做竞品调研、内容选题、短视频脚本、线索筛选和 GEO 素材产出。定位是「免费获客 + IP 内容运营」，3 到 8 人的运营小组用得最多。

它和偏代码执行的 Codex、偏办公文档自动化的 Workbuddy 不是一类东西——前者写代码跑程序，后者管内部文件和任务，天天获客 Agent 管的是「怎么被更多人看见、怎么把看见的人接住」。

能做什么

  • 竞品调研：把同类账号的内容、选题、评论区需求拉出来，整理成可用的结论
  • 内容选题：从真实评论和搜索需求里挑题，不靠拍脑袋

    常见问题

    天天获客 Agent 和 Workbuddy 有什么差别？
    Workbuddy 主打办公文件、内部任务自动化；天天获客 Agent 专门做获客、内容调研、引流素材。
    支持私有化部署吗？对外卖吗？
    目前是自用＋小范围内测阶段，还没有对外开放的在线产品。想要试用名额，在抖音私信「试用」。
    适合谁用？
    AI 产品运营、短视频 IP、做免费获客的小团队，3 到 8 人的运营组最合适。
